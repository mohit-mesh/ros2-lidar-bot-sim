# 🤖 ROS 2 LiDAR Mobile Robot Simulation

An end-to-end ROS 2 simulation package featuring a LiDAR-equipped mobile robot platform operating in Gazebo, complete with `ros_gz_bridge` topic remapping and RViz2 point cloud visualization.
